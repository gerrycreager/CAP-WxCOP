ℹ️ Important Information

Testing System: This system is for testing purposes only and complies with constraint guidelines found in CAPR 70-1 regarding wind limits.

Data Source: ALL data derived solely from US Government sources. Wind analysis uses NOAA HRRR (High-Resolution Rapid Refresh) model data. Airport information from OurAirports database. Airports shown have paved runways of 2,500 feet or more.

Forecast Period: Analysis covers a 12-hour period from model initialization time (forecast hours 0-12). Maximum winds during this 12-hour window are displayed.

Regional Sub-Divisions: Pacific Region (PCR) and Southeast Region (SER) are divided into geographic sub-regions due to their separation by thousands of miles. Only the sub-regions are available for selection to ensure readable, properly-zoomed maps (e.g., PCR-West Coast shows CA/NV/OR/WA; PCR-Hawaii shows HI; PCR-Alaska shows AK).

50nm Radius Mode: Enter an airport ICAO code (e.g., KMXF) to center on that airport, or provide a CAP Grid name with latitude/longitude coordinates. The map will show all qualifying airports within 50 nautical miles.

Coordinate System: All shapefiles are provided in WGS84 geographic coordinates (EPSG:4326). Shapefile downloads include all necessary component files (.shp, .shx, .dbf, .prj, .cpg) packaged as zip files.

Process: When you request a map, the server locates the latest forecast cycle, fetches any missing forecast files, samples winds at qualifying airports, and generates a high-resolution image and shapefiles for download.

⚠️ This is NOT an official CAP website.
