WxCOP User Guide

How to use every tool in the CAP WxCOP suite — one page, grouped by what you're trying to get done rather than by how the software happens to be built.

Status: this pass covers how to use each tool — every control, button, and field. Technical appendices (data sources, refresh cadence, known limitations for maintainers) are coming in a follow-up pass. A couple of real issues turned up during this review anyway; they're called out in place below rather than held back.
Flight Planning

Enhanced Weather Map /enhanced-weather-map

The main situational-awareness map: radar, satellite, lightning, airspace, hazards, and winds layered over airports and METAR stations. This is the day-to-day map for "what's going on out there right now," not a single-airport forecast tool.

Airports & Labels
Military Airfields / Major Hubs / Regional Airfields (≥7000 ft) / Local Airfields (5000–6999 ft) / Small Airfields (2500–4999 ft)
Five independent toggles controlling which tier of airport shows on the map. Regional and Local are on by default; Small is off, since it's the densest tier and clutters the view at low zoom.
Show labels
Prints each airport's identifier next to its marker.
Wind barbs + station plots
Shows live METAR data at each station — wind barb, temperature/dewpoint, sky condition, ceiling, visibility, gust — with the amount of detail shown increasing as you zoom in, so the map stays readable at a CONUS-wide view.
No-METAR Airfields
Shows paved airfields that don't have a reporting weather station, so you know a field exists even where there's no observation to show.
Airspace & Hazards
TFRs
Active Temporary Flight Restrictions.
AIRMETs / SIGMETs
Current in-flight weather advisories.
FZLVL Contours
Freezing-level contour lines.
GLM Lightning
Satellite-observed lightning strikes (GOES Geostationary Lightning Mapper), not radar-inferred.
NWS Watches/Warnings
Active NWS watch/warning/advisory polygons.
Special Use Airspace
Prohibited (P-) / Restricted (R-) / MOA / Warning / Alert / Mil Training Routes (MTR)
Four independent toggles for the different classes of special-use and military airspace.
Radar
Local Radar (auto)
One toggle. The map automatically picks the right radar source for your current view — a wide-area mosaic (MRMS) when zoomed out, or the nearest single WSR-88D (or airport TDWR) site once you're zoomed in close to it. You don't choose the source yourself.
Reflectivity (N0B) / Hydrometeor Class (N0H) / Storm-Relative Velocity (N0S)
Appear only when a single WSR-88D site is active — pick which radar product to display.
Refl 48nmi T1–T3 (TZ0–TZ2) / Long Range Refl (TZL)
Appear only when an airport TDWR is active — four tilt/range reflectivity products.
Radar opacity
Slider, 0–100%.
TRW Probability (LAMP)
Model-forecast thunderstorm probability, as a separate overlay from the observed radar above.
Satellite
GOES Satellite
Master toggle.
IR (Cloud Tops) / Visible / Water Vapor
Pick one product.
Opacity
Slider.
Animate
Loops the satellite imagery, using the same timeline/duration control as the radar loop.
Precipitable Water
GOES TPW (background)
Total precipitable water, shown as a background layer, with its own opacity slider.
Wind Flow
Animated Wind
Master toggle for the particle-animation wind layer.
Source
Currently HRRR, labeled "best effort" in the UI — it's nearest-neighbor regridded from HRRR's native grid, so treat it as a visual guide to flow patterns, not a precision aviation product.
Level
Surface, NEW 1,000 ft AGL (the standard search/aerial-photography altitude — calculated relative to actual ground elevation at every point on the map, not a flat band), 850 / 700 / 500 hPa, or Deep-Layer Mean (an 850–700–500 hPa steering-flow average, most useful for watching a tropical system's likely track).
Opacity
Slider.

Whichever animated layer is currently on — radar loop, satellite animation, or wind particles — shares one play/pause/step timeline bar at the bottom of the map.

Flight Ops Impacts /weather-impacts

Hour-by-hour Go/Caution/No-Go forecast for flight operations at any airport, built from CAPR 70-1-style thresholds (a given Wing can tighten these via Wing ICL Admin — see below).

Go Caution No-Go No Data
CaveatThese three colors now also carry CAPR 70-10 release-authority meaning, not just a raw weather-severity read: Go lines up with an FRO-releasable flight, Caution with one needing SFRO (or SFRO + Wing CC) sign-off, and No-Go with one that needs CAP/DO. Same thresholds as before — the colors just reflect who has to approve the flight, not only how marginal the weather is.
Operation Type — VFR Fixed Wing / IFR Fixed Wing
Switches which ceiling/visibility thresholds apply to the stoplight.
Forecast Hour
Slider (1–25) plus quick-pick hour buttons below it; the label shows the actual valid time for whichever hour you land on.
Find Airport
Type an ICAO identifier (e.g. KLSF) and click Go to jump straight to it.
Airport labels
Toggle identifier text on the map.
Live METAR Station Plots
Overlays real observed conditions, so you can compare "what's actually happening right now" against the forecast stoplight for the same hour.
Radar Composite
MRMS radar mosaic overlay.
GLM Lightning
Satellite-observed lightning.
NWS Watches/Warnings
Active watch/warning/advisory polygons.
AIRMETs/SIGMETs
Current in-flight advisories.
Streamlines (HRRR)
Wind-flow overlay. Pick a level: Surface, NEW 1,000 ft AGL (search/photo) — terrain-relative, unlike the bands below it — then ~3,000 / ~6,000 / ~10,000 / ~12,000 / ~18,000 ft MSL.
PM2.5 Contour (IDW) — AirNow
Smoothed contour built from real AirNow monitoring stations, with its own opacity slider.
Near-Surface Smoke — HRRR Forecast
A modeled (not observed) smoke layer, with its own opacity slider. It uses the same EPA AQI color scale as the AirNow layer above — the two are meant to be compared against each other, not trusted individually.

A FITS (Thermal Stress) legend is shown as a quick reference on this page. For an actual calculation at a specific location and time, use the WBGT Calculator instead.

Clicking any airport opens a detail panel: a color banner, a parameter grid, a 25-hour forecast table (ceiling, visibility, wind, crosswind, temperature, thunderstorm probability), and a 📄 PDF button to download a report for that station.

Mission TAF / MEF Delivery

This one isn't a page you browse to — it's how a Mission Execution Forecast (MEF) actually gets to you, and it's worth knowing how the pieces fit together.

Automated MEF delivery
For the missions it's set up for, a scheduled job pulls the freshest model data ahead of the launch window, builds the full MEF packet — route legs and timeline, winds aloft by leg, a surface-conditions table, go/no-go notes, and caveats — as a PDF, and emails it to the mission's distribution list. There's nothing to log into; just check your inbox before the stated deadline.
The model-TAF feed behind the laptop MEF tool
A backend data service, with no page and no login, that Gerry's laptop-side MEF tool calls directly to pull model-derived TAF text for any station. It's deliberately not something you browse to.
Looking at the raw text yourself
If you ever need to sanity-check what the laptop tool pulled, the fixed-cluster feed prints plain TAF-formatted text at a bare URL. It isn't linked from anywhere in WxCOP by design — ask Gerry for the current address if you need it.
Cadet Safety

Cadet Weather COP /cadet-wx

The live, right-now view: is it currently safe to be outside at each cadet site — not a forecast.

Known issueNo login is required to view or act on this page's data. Flagged for awareness, not yet fixed.
Site list / map markers
Colored by a composite stoplight — the worst of seven categories wins. Click a site to open its detail panel.
Detail panel
Shows a data-source badge ("📡 METAR (observed)" or "🔢 Model F00 (analysis)" — whichever is more current for that site), a color banner, and a 7-box category grid: Heat Stress, Cold Stress, Lightning, Surface Wind, Precip, NWS Hazards, Air Quality (PM2.5). Below that: temperature, dewpoint, heat index, wind chill, wind, precip rate, WBGT, and PM2.5 with distance to the nearest AirNow station, plus any active NWS alerts for that location.
⚡ GLM Lightning
"Show lightning flashes" toggle + a Last 5/15/30-minute window selector. Red dot = 0–5 min old ("stop if within 5NM"), yellow = 5–15 min ("caution"), green = 15–30 min ("resume if clear"). "Show Local Radar (auto)" adds the same auto-selecting radar layer as the Enhanced Weather Map.
💨 Smoke (HRRR)
"Show near-surface smoke" — a modeled layer with an opacity slider and its own play/pause animation bar.
🌡 Air Quality (Observed)
"Show AirNow PM2.5 contour" — labeled in the page itself as a prototype, since it's sparse away from monitoring stations. The page recommends comparing it against the HRRR smoke layer rather than trusting either alone.
◎ Range Rings
"Show 5/15/25 NM rings" — fixed reference circles, independent of each site's own configured warning/watch radius.
Future workSMS lightning alerts (WARNING/WATCH on radius entry, ALL CLEAR 15 minutes after the last strike) are designed in but not operational — the carrier-side SMS service was never successfully integrated. Treat the map/detail panel as the live source of truth for now; don't rely on a text arriving.

Cadet Weather Planning /cadet-wx-plan

The forward-looking counterpart to Cadet Weather COP: a forecast-hour stoplight for every active cadet site, for deciding in advance whether an activity will be safe at a specific future hour.

Forecast Hour slider (1–18)
Drag to a future hour; the label above shows the actual valid time (UTC).
Quick-select buttons
Jump straight to a specific hour without dragging — relabeled with real valid times once data loads.
Sites list
Click any site to select it on the map and open its detail panel.
GLM Lightning toggle + window dropdown
Overlays recent real lightning strikes on top of the forecast view — this part is observed, not forecast.
Detail panel
Shows the selected site's stoplight color, the same category grid as Cadet Weather COP, and a full forecast table you can step through hour by hour.
GO — no restrictions CAUTION — monitor, adjust STOP — suspend/shelter No data

Cadet Site Management /cadet-sites/manage

The admin form for adding, editing, and removing the sites that appear on both the COP and Planning maps.

Known issueNo login is required to create, edit, or delete sites or manage recipients — anyone who can reach the page URL can do all of this. Flagged for awareness, not yet fixed.
Add New Site form
Site Name*, Short Name, CAP Region* (dropdown), Nearest ICAO Station (optional — leave blank if none nearby), Latitude*/Longitude*, Elevation (ft MSL), Activity Type (Encampment / Flight Academy / Ranger School / SLS / CLS / NCSA / Other), Lightning Units (NM/SM/KM), Warning Radius (default 10), Watch Radius (default 20). Required fields are marked *.
Save Site / Cancel
Save creates or updates; Cancel clears the form.
Manage / Edit / Delete
Per-site row actions. Delete only confirms via the browser's own prompt — be deliberate.
Manage panel — recipients
Add a recipient by Name + 10-digit phone, and a Test SMS button are present in the UI, but neither currently sends anything — see the Future work note on Cadet Weather COP. The recipient list itself still saves, ready for when SMS delivery is working.
Heat & Health

WBGT Calculator /wbgt

Computes Wet Bulb Globe Temperature — the heat-stress index CAP uses to set activity limits during outdoor training, encampments, and PT — from basic weather inputs, and reports which DAFI 48-151 flag condition currently applies.

Entering conditions
Temperature
Numeric field; toggle °F / °C next to it.
Dewpoint / Relative Humidity
Toggle between Td and RH% — the field and its expected range change with the mode.
Wind Speed
Toggle kts / mph.
Station Pressure (optional)
hPa — leave blank if unknown.
Latitude / Longitude
Decimal degrees. These drive the solar-angle calculation — fill them in for an accurate sun-exposure estimate rather than a rough fallback.
Date (UTC) / Time (UTC)
Date picker + hour field, or click Now to auto-fill both.
Sky Condition
Overcast/Shade, Partly Cloudy, or Clear/Full Sun. A live "Solar elevation… Est. DSWRF…" note appears once location and time are filled in, so you can sanity-check the sun angle being used.
Auto-filling conditions instead of typing them in
Load from Cadet Site
Pick a site from the dropdown, click Load Wx — fills in location and that site's current conditions if available.
Load from Nearest METAR Airport
Click Use Current Lat/Lon → Find Nearest Station, pick from the 5 nearest reporting airports shown, then Load Conditions from Selected Station.
▶ Calculate WBGT
Runs the calculation. Results show: a large colored WBGT readout labeled with the current flag (White/Green/Yellow/Red/Black); the full DAFI 48-151 Ch.4 Table 4.1 activity-guidance table with your flag's row highlighted; and secondary readouts (Wet Bulb Temp, Globe Temp, Heat Index, Wind Chill) — the page explicitly notes WBGT, not Heat Index, is the authoritative metric for setting limits.
CaveatIf latitude/longitude/date/time are left blank, the solar input falls back to a rough fixed estimate per sky-condition button rather than a real sun-angle calculation. Fill in location and time for an accurate result.

NWS HeatRisk

Not a WxCOP page — a card on the WxCOP home page, under Heat Risk & Health, that links out to NOAA's own HeatRisk tool (opens in a new tab, marked LIVE / EXT). WxCOP doesn't compute or display this data itself.

It's a 7-day, color-coded forecast of daily heat-illness risk for a location you choose on NOAA's site — useful for encampment and ground SAR planning further out than the WBGT Calculator's point-in-time reading for an activity happening right now.

↗ Opens NOAA's Weather Prediction Center HeatRisk tool in a new tab.

Records & Administration

Incident Archive /incident-archive

Builds a downloadable ZIP of weather data around a specific time and place, for reconstructing conditions after an aviation incident — not a routine monitoring tool.

  1. Location — three tabs: Airport ID (ICAO identifier, e.g. KCOS — falls back to that station's most recent METAR if the airport itself isn't found), Lat/Lon (decimal degrees or degrees–decimal-minutes, e.g. 38 48.348N), or MGRS (10-digit grid coordinate).
  2. Incident Time (UTC) — pre-filled to one hour before now as a starting point; all times are UTC.
  3. Collection Radii — METAR/TAF (nm, default 100) and Radar (nm, default 140), each adjustable 10–300.
  4. Preview — queries without downloading; shows station/report counts, radar sites in range, and plots the incident location, METAR/TAF radius (blue circle), and radar radius (orange dashed circle) on the map. Generate ZIP stays disabled until Preview succeeds.
  5. Generate ZIP — downloads a file named like incident_20261011_1430Z_KCOS.zip, containing METARs/SPECIs (6-hour window), TAFs valid at the incident time (24-hour lookback), georeferenced radar PNGs (±1 hour), a satellite-download instructions file (manual download steps, not actual imagery yet), and a metadata/README summary.
Known limitationsRadar site markers on the preview map aren't wired to real coordinates yet — only the incident marker and the two radius circles reliably render. Satellite imagery is instructions-only in this version; the ZIP's satellite folder won't contain actual image files.

Wing ICL Admin /admin/wing-icl

For Wing Directors of Operations and Stan/Eval officers to tighten — never loosen — CAPR 70-1/CAPF 70-1A weather Go/No-Go thresholds for their own wing. Requires login; NHQ/admin users manage every wing's overrides, a wing-role user only their own.

National Defaults banner
Reference strip of baseline thresholds every wing starts from with no override: Surface Wind (Caution 21 kt / No-Go 30 kt), Crosswind VFR (8/15 kt), Crosswind IFR (8/13 kt), Cold Temperature (Caution 20°F / No-Go -10°F), Ceiling VFR (Caution 2,000 ft / No-Go 1,000 ft), Visibility VFR (Caution 3.0 SM / No-Go 1.0 SM).
Add / Update Override form
Wing/Region (admin only — wing-role users see their own wing, read-only), Parameter (grouped dropdown; auto-fills the unit and a regulation hint), Threshold (its min/max auto-constrains to the conservative side the instant you pick a parameter — you can't type a looser value), Regulation/Authority (free text), Effective/Expires dates, Notes. Save Override creates or, if you re-save the same wing+parameter, overwrites the existing one.
Current ICL Overrides table
One row per active override, with a side-by-side ICL-vs-National comparison and a Delete button (confirmed via a prompt) on each row. A wing with no overrides is shown explicitly as running on national defaults.

The core rule, stated permanently above the form: overrides may only be more conservative — never more lenient — and ceiling/visibility overrides must trigger sooner (higher numbers), not later.

Manual TAF Entry /manual-taf

For entering a TAF by hand when it doesn't arrive automatically over the normal feed — primarily KQ-prefixed USAF placeholder stations, plus any civilian ICAO that AF Weather issues TAFs for directly.

TAF Raw Text
Paste the complete raw TAF exactly as received. Station ID, issue time, and validity period are parsed automatically out of the text — you don't fill those in separately. Plain TAF, TAF AMD, and TAF COR are all recognized.
↑ Submit TAF
Disables and shows "Submitting..." while it saves. On success, a confirmation shows the parsed station, name, issue time, and validity window, and the form clears itself after 3 seconds. On failure, an error explains why — if the station isn't found in the database, it redirects you to KQ Station Management after 2 seconds to add it first.
Clear Form
Wipes the text box without submitting.
Known KQ & AF Weather Airfields reference
Lists every currently-known station purely for reference — the form itself accepts a TAF for any station already in the airports database, not just the ones listed.

Recent Manual TAFs /manual-taf/recent is the history view, reached via the nav link on the entry page — the last 20 manually-entered TAFs, each showing station, issue time, valid window, and a text preview (hover for the full text). It links back to Add TAF, Manage KQ Stations, and Incident Archive, so the two pages are meant to be used back and forth.
