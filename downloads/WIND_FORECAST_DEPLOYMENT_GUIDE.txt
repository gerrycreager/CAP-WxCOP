WIND FORECAST SYSTEM - COMPLETE DEPLOYMENT GUIDE
================================================

This system provides 12-hour wind forecasts from TWO sources:
1. HRRR/GFS model forecasts (numerical weather models)
2. TAF forecasts (terminal aerodrome forecasts)

You can generate forecast maps showing expected winds for the next 12 hours
from either source, allowing comparison between model and TAF forecasts.


OVERVIEW OF COMPONENTS
======================

Database:
  - observations.model_wind_forecasts (HRRR/GFS forecasts by hour)
  - observations.taf_wind_forecasts (TAF forecast periods)
  - observations.wind_forecast_snapshots (pre-computed snapshots)

Ingest Scripts:
  - ingest_model_winds.py (extracts winds from GRIB files)
  - populate_taf_winds.py (parses winds from TAFs)

Visualization:
  - Generate maps showing forecast winds (next step)
  - Compare model vs TAF forecasts
  - Show worst-case 12-hour max winds

STEP 3: Test Model Wind Ingest
-------------------------------
# Test HRRR ingest
sudo -u www-data /var/www/cap_winds_app/scripts/ingest_model_winds.py --model HRRR --hours 12

# Check results
sudo -u postgres psql -d avwx_data -c "
SELECT 
    model_name, 
    model_run, 
    COUNT(*) as forecast_count,
    COUNT(DISTINCT station_id) as airport_count,
    MIN(valid_time) as first_fcst,
    MAX(valid_time) as last_fcst
FROM observations.model_wind_forecasts
GROUP BY model_name, model_run
ORDER BY model_run DESC
LIMIT 5;

QUERYING THE DATA
=================

Get model forecast for specific airport:
----------------------------------------
sudo -u postgres psql -d avwx_data -c "
SELECT * FROM get_current_model_winds('KDFW', 12);
"

Output shows hourly forecasts for next 12 hours


Get TAF forecast for specific airport:
---------------------------------------
sudo -u postgres psql -d avwx_data -c "
SELECT * FROM get_current_taf_winds('KDFW');
"

Output shows TAF forecast periods


Get maximum winds in next 12 hours (model):
--------------------------------------------
sudo -u postgres psql -d avwx_data -c "
SELECT * FROM get_max_forecast_winds('KDFW', 12, 'MODEL');
"


Get maximum winds in next 12 hours (TAF):
------------------------------------------
sudo -u postgres psql -d avwx_data -c "
SELECT * FROM get_max_forecast_winds('KDFW', 12, 'TAF');
"


Find all airports with EXTREME winds forecast:
-----------------------------------------------
sudo -u postgres psql -d avwx_data -c "
SELECT DISTINCT 
    station_id, 
    MAX(wind_speed_kts) as max_wind,
    MAX(wind_gust_kts) as max_gust
FROM observations.model_wind_forecasts
WHERE wind_category = 'EXTREME'
  AND valid_time BETWEEN NOW() AND NOW() + INTERVAL '12 hours'
  AND model_run = (SELECT MAX(model_run) FROM observations.model_wind_forecasts)
GROUP BY station_id
ORDER BY max_wind DESC
LIMIT 20;
"


Compare model vs TAF forecasts:
--------------------------------
sudo -u postgres psql -d avwx_data -c "
SELECT 
    m.station_id,
    m.valid_time,
    m.wind_speed_kts as model_wind,
    t.wind_speed_kts as taf_wind,
    ABS(m.wind_speed_kts - t.wind_speed_kts) as difference,
    m.wind_category as model_category,
    t.wind_category as taf_category
FROM observations.model_wind_forecasts m
JOIN observations.taf_wind_forecasts t 
  ON m.station_id = t.station_id
  AND m.valid_time BETWEEN t.valid_from AND t.valid_to
WHERE m.valid_time > NOW()
  AND m.model_run = (SELECT MAX(model_run) FROM observations.model_wind_forecasts)
ORDER BY difference DESC
LIMIT 20;
"

TROUBLESHOOTING
===============

Issue: No model winds being ingested
Solution:
  - Check GRIB files exist: ls -lh /LDM/models/hrrr/hrrr.$(date -u +%Y%m%d)/*/
  - Check pygrib installed: python3 -c "import pygrib; print('OK')"
  - Run manually with verbose logging
  - Check /var/log/model_winds.log for errors

Issue: TAF parsing producing no results
Solution:
  - Check TAFs in database: SELECT COUNT(*) FROM observations.taf;
  - Check raw TAF format: SELECT raw_text FROM observations.taf LIMIT 1;
  - TAF parser is simplified - may need enhancement
  - Check /var/log/taf_winds.log for errors

Issue: Database getting too large
Solution:
  - Set up data retention (cleanup old forecasts)
  - Keep model forecasts for 7 days
  - Keep TAF forecasts for 7 days
  - Add cleanup to cron


DATA RETENTION
==============

Add to cleanup_old_data.sh:

# Clean old model wind forecasts (keep 7 days)
sudo -u postgres psql -d avwx_data -c "
DELETE FROM observations.model_wind_forecasts
WHERE model_run < NOW() - INTERVAL '7 days';
"

# Clean old TAF wind forecasts (keep 7 days)
sudo -u postgres psql -d avwx_data -c "
DELETE FROM observations.taf_wind_forecasts
WHERE taf_issue_time < NOW() - INTERVAL '7 days';
"

# Vacuum
sudo -u postgres psql -d avwx_data -c "VACUUM ANALYZE observations.model_wind_forecasts;"
sudo -u postgres psql -d avwx_data -c "VACUUM ANALYZE observations.taf_wind_forecasts;"
