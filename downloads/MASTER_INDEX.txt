DEPLOYMENT SEQUENCE
===================

PHASE 1: Core Web App (5 minutes)
----------------------------------
cd /var/www/cap_winds_app

# Deploy new Flask app
cp app.py.old app.py.backup  # backup old
cp app.py /var/www/cap_winds_app/app.py
systemctl restart apache2

# Test
curl http://localhost/
curl http://localhost/api/status

Expected: Web interface loads, API returns status


PHASE 2: Batch Generation (10 minutes)
---------------------------------------
# Deploy batch scripts
cp batch_generate_maps_corrected.py /var/www/cap_winds_app/batch_generate_maps.py
cp batch_generate_all_maps.py /var/www/cap_winds_app/
chmod +x /var/www/cap_winds_app/batch_generate*.py

# Test regional generation (20 min)
sudo -u www-data /var/www/cap_winds_app/batch_generate_maps.py

Expected: 13 maps in /var/www/html/cap_winds/ with static names


PHASE 3: Wind Forecast System (15 minutes)
-------------------------------------------
# Create database schema
sudo -u postgres psql -d avwx_data -f wind_forecast_schema.sql

# Verify
sudo -u postgres psql -d avwx_data -c "\dt observations.*wind*"

# Deploy ingest scripts
cp ingest_model_winds.py /var/www/cap_winds_app/scripts/
cp populate_taf_winds.py /var/www/cap_winds_app/scripts/
chmod +x /var/www/cap_winds_app/scripts/*.py

# Install dependencies
pip install pygrib psycopg2-binary --break-system-packages

# Test model wind ingest
sudo -u www-data /var/www/cap_winds_app/scripts/ingest_model_winds.py --model HRRR

Expected: ~15,000-20,000 forecasts inserted


PHASE 4: Configure Cron (10 minutes)
-------------------------------------
sudo crontab -u www-data -e

Add these jobs:

# METAR ingest (every 15 min)
*/15 * * * * /var/www/cap_winds_app/scripts/ingest_metar.py --recent 20 >> /var/log/metar_ingest.log 2>&1

# TAF ingest (hourly)
5 * * * * /var/www/cap_winds_app/scripts/ingest_taf.py --recent 90 >> /var/log/taf_ingest.log 2>&1

# Regional batch maps (hourly)
5 * * * * /var/www/cap_winds_app/batch_generate_maps.py >> /var/log/batch_maps.log 2>&1

# Complete batch maps (every 3 hours)
5 */3 * * * /var/www/cap_winds_app/batch_generate_all_maps.py --all >> /var/log/batch_maps_all.log 2>&1

# Model winds - HRRR (hourly)
15 * * * * /var/www/cap_winds_app/scripts/ingest_model_winds.py --model HRRR >> /var/log/model_winds.log 2>&1

# Model winds - GFS (every 6 hours)
25 */6 * * * /var/www/cap_winds_app/scripts/ingest_model_winds.py --model GFS >> /var/log/model_winds.log 2>&1

# TAF wind parsing (hourly)
30 * * * * /var/www/cap_winds_app/scripts/populate_taf_winds.py --recent 2 >> /var/log/taf_winds.log 2>&1


PHASE 5: Test & Verify (20 minutes)
------------------------------------
# Wait for cron jobs to run, or manually trigger:

# Test CONUS map request (should be < 1 second)
time curl http://localhost/?selection_type=conus

# Check database
sudo -u postgres psql -d avwx_data -c "
SELECT 
    'METARs' as table, COUNT(*) as count FROM observations.metar
UNION ALL
SELECT 'TAFs', COUNT(*) FROM observations.taf
UNION ALL  
SELECT 'Model Winds', COUNT(*) FROM observations.model_wind_forecasts
UNION ALL
SELECT 'TAF Winds', COUNT(*) FROM observations.taf_wind_forecasts;
"

# Check batch maps
ls -lh /var/www/html/cap_winds/*.png | wc -l
# Should show 13 (or 64 if complete batch ran)

# Monitor logs
tail -f /var/log/batch_maps.log


SYSTEM ARCHITECTURE OVERVIEW
=============================

Data Flow:
----------
LDM → GRIB files → ingest_model_winds.py → PostGIS model_wind_forecasts
LDM → Text products → ingest_metar/taf.py → PostGIS observations
TAF database → populate_taf_winds.py → PostGIS taf_wind_forecasts

Map Generation:
---------------
Scheduled → batch_generate_maps.py → Static PNG files
User request → Flask app → Check batch maps first → Serve instantly
             ↓ (if no batch map)
             → states_service.py → Generate on-demand → Serve

Performance:
------------
Before: Every request generates map (1-20 minutes)
After:  Regional requests serve batch maps (< 1 second)
        State/radius requests still generate (1-3 minutes)
        80-90% of requests now instant!
